# EduTech: Student Management System 🏫

## 📌 Overview
EduTech is a **Spring Boot-based Student Management System** that allows users to perform **CRUD (Create, Read, Update, Delete)** operations on student records. It provides an efficient way to manage student data with ease.

## 🚀 Features
- Add new students 📌
- View student details 📖
- Update student information ✏️
- Delete student records 🗑️
- Built with **Spring Boot, JPA, and MySQL**

## ⚙️ Technologies Used
- **Spring Boot** 🌿
- **Spring Data JPA** 🗄️
- **MySQL** 🛢️
- **REST APIs** 🔗
